# SpendLens – Credit Card Spend Analyzer

## What it does
Analyzes credit card statements to:
- Categorize spending
- Detect waste and penalties
- Highlight savings opportunities

## How to use
1. Upload your credit card Excel statement
2. View categorized insights
3. Follow recommended actions

## Key Features
- Merchant-level analysis
- Refund tracking
- Spend classification
- Savings insights
